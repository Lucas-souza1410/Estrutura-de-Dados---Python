# Estrutura de Dados — Python

##  Sobre o projeto

Este repositório contém atividades e exercícios desenvolvidos durante a disciplina de **Estrutura de Dados**, utilizando a linguagem Python.

O objetivo do projeto é aplicar conceitos fundamentais de programação, desenvolver o raciocínio lógico e praticar a resolução de problemas por meio de códigos em Python.

##  Tecnologias utilizadas

- Python 3
- Google Colab
- Jupyter Notebook

##  Estrutura do projeto

- `N2_Ed.ipynb` — Notebook com atividades, exercícios e implementações desenvolvidas durante a disciplina.

##  Objetivos de aprendizagem

- Praticar lógica de programação.
- Desenvolver algoritmos utilizando Python.
- Trabalhar com estruturas condicionais e de repetição.
- Aprimorar a resolução de problemas.
- Desenvolver conhecimentos fundamentais de Estrutura de Dados.

##  Como executar

1. Acesse o arquivo `N2_Ed.ipynb`.
2. Clique em **Open in Colab**.
3. Execute as células do notebook para visualizar e testar os códigos.
